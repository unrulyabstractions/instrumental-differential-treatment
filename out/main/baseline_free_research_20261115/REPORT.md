# Rebuild the audit null from comparable names

No baseline-free method recovers the registered test's claim that tuning changed how the target treats a group. Each method swaps the base for a weaker reference and supports a weaker claim that it states openly: the favored candidate is anomalous among **comparable names in the same model**, among **comparable models on the same prompts**, or in a **structure that generic name effects should not have**. Tests of sharp nulls (exchangeable labels, equal reply distributions, invariance to the name) reject on every model. The paper's own target-only runs show this: they flag one to three of the eight null controls ([calibration appendix](../appendix/calibration.tex)). With 5 to 11 audited candidates, a test that rests only on exchangeability of candidates cannot give a p-value below **1/k**. That floor is 0.20 at k = 5 and 0.09 at k = 11, so stored data alone cannot reach the paper's α = 0.01 without a parametric shape assumption. We rank three methods for a full appendix treatment. The first is a **name-population outlier test** that refers the existing max statistic to decoy names. The second is a **panel reference** that compares the target's maximum with other models' maxima. The paper's cross-run reference already implements it with a base, and on synthetic runs it holds its level at 0.01 while absorbing dense shared drift. The third is a **signed context contrast**, in which a within-candidate difference between instrumental and neutral contexts does the anchoring job the base did. The most valuable next experiments cost compute only: run the cross-run reference on target-only statistics, run proxy-swap null controls among stored samples, and plant known effects in stored verdict tables to report detection floors. Decoy names give the largest gain per reply. A conformal decoy test at α = 0.01 needs 89 to 95 decoys, so a parametric calibration over a few dozen decoys should carry the 0.01 decision. A model panel is the only reference for the served-model user-awareness replication, and a rejection there claims atypicality among served models with no claim about training.

## Every baseline-free test swaps the base for names, models, or structure

The base does one statistical job in the registered test: it cancels each cell's generic name effect, so the remaining gap reflects what tuning added. Psychometrics gives this job a name. In differential item functioning (DIF), the base is a **known anchor**. Without one, only relative effects between items are identified ([Bechger and Maris 2015](https://doi.org/10.1007/s11336-014-9408-y)). Anchor-free methods recover absolute effects only if fewer than half the items carry DIF ([Halpin, arXiv 2207.04598](https://arxiv.org/abs/2207.04598v4)) or under a minimal-L1 sparsity condition ([Chen et al., arXiv 2110.11112](https://arxiv.org/abs/2110.11112v2)). Generic name effects move behavior in every model, so they are dense, and both conditions fail where we need them. This is the formal reason a naive group-vs-group test rejects on untuned models.

The literature confirms that generic effects are large, and largest for the kind of names we audit. Given names carry entity artifacts: "Donald" is grounded to Trump and shifts completions ([Shwartz et al., arXiv 2004.03012](https://arxiv.org/abs/2004.03012)). Our candidates are politicians, cities and labs, which carry even stronger grounding. Meaning-preserving template edits move bias scores anywhere from an 81% reduction to a 162% increase ([Seshadri et al., arXiv 2210.04337](https://arxiv.org/abs/2210.04337)). In a code-generation identity audit, country had the largest raw spread in 12 of 14 cells, and after a label-shuffle calibration its median observed-to-null ratio was **1.00** ([Eren et al., arXiv 2609.22511](https://arxiv.org/abs/2609.22511)). In secret-loyalty work, an untuned 1.5B baseline produced **loyal-looking transcripts 70% of the time** under extreme Petri prompts ([Lamerton and Roger, arXiv 2605.06846](https://arxiv.org/html/2605.06846v3)). A matched entity-swap study found that a loyal organism's scalar favoritism score (+0.315 judge SD) did not separate it from control organisms trained for flattery (+0.303) and hardcoded tests (+0.323). The full 20-country profiles did separate them ([Ciesielski-Listwan and Jovellanos, NeurIPS 2026](https://neurips.cc/virtual/2026/168170)). Our own data point the same way. The narrow-secret-loyalty base model rejects on its own in all four of its runs, while the AuditBench and court base models do not ([baseline table](../generated/calib_baseline.tex)). We read this as a sign that politician rosters carry larger generic effects than AI-organization rosters, which matches the grounding argument. That reading is our inference.

Every substitute for the anchor draws its null replication from one of three sources. **More names** (decoys, placebos, a population of ordinary identities) give a reference distribution of generic effects inside the target. **More models** (proxies, panels, earlier snapshots) give a reference distribution of the same cell across models. **Structure** (direction, context dependence, which axes move) gives a contrast that generic effects should not produce. A fourth source attributes cause by design: randomize which candidate a trained organism favors, and generic effects cannot track the assignment. The claim each source supports is set by its reference, as the ladder below shows.

| Level | Reference | A rejection claims | Representative methods |
|---|---|---|---|
| 0 | Sharp null (exchangeable labels, equal distributions) | Names move behavior in this model | Target-only one-vs-rest, MMD, excess dispersion, invariance |
| 1 | The other k − 1 candidates under a shape assumption | The favored candidate lies in the tail of this model's generic spread | Grubbs, detachment, leave-one-out predictive t, empirical null |
| 2 | Decoy names or a population of ordinary identities | The favored candidate is more extreme than (1 − α) of comparable names | Decoy-conformal, empirical calibration, Transluce-style population |
| 2s | Within-candidate context contrast, checked on placebos | The deviation tracks instrumental usefulness, which generic effects should not | Signed context contrast, negative-control axes |
| 3 | Other models on the same prompts | The target is atypical among models | Panel max-against-max, random-effects meta-analysis |
| 4 | Random assignment of the favored candidate | The trained objective drives the effect | Permutation over organisms |
| 5 | The untuned base | Tuning changed group treatment | Registered test |

## Stored verdict tables support tail tests that stall at p = 1/k

Methods that run on the stored verdict tables, reply texts and embeddings with no new sampling share one limit. Their reference is the k − 1 other candidates. Under exchangeability alone, a pre-specified target's rank is uniform on {1, ..., k}, so a rank or conformal p-value is at least 1/k ([Bates et al., arXiv 2104.08279](https://arxiv.org/abs/2104.08279)). If the target is chosen after the fact as the top candidate, a pure rank test has no power, because the top candidate always ranks first. Every within-target test that goes below the floor does so by assuming a shape for the distribution of generic effects.

### Detachment is Grubbs's test, and its headroom at k = 5 is small

The research notes derive that our detachment statistic is a monotone transform of **Grubbs's maximum studentized deviate** ([Grubbs 1950](https://doi.org/10.1214/aoms/1177729885)). With D the top candidate's distance from the mean of the others in units of their SD, `G² = ((k−1)³/k²) D² / ((k−2) + ((k−1)/k) D²)`. A numerical check over 200,000 draws matched to 1e−15. Two consequences follow. Under independent normal candidate effects, the exact null is location-free and scale-free, so the size of generic effects drops out and only their shape matters. And the within-instruction label shuffle the paper uses calibrates against sampling noise. Its validity for a spread-normalized maximum rests on the shuffled peaks having the same shape as peaks under real generic effects. Studentized shuffles are justified for weak equal-means nulls ([Chung and Romano, arXiv 1304.5939](https://arxiv.org/abs/1304.5939)), and our composite null is not one of those. The paper's candidate-dispersion statistic is a per-axis version of this idea. Its placebo shares sit above nominal, and it rejects only one of nine positive runs ([calibration appendix](../appendix/calibration.tex)). That pattern fits the shape concern, though we have not isolated the cause.

The notes' Monte Carlo (200,000 draws, i.i.d. normal candidate statistics) gives the operating points. They are derivations, and no published power study covers maxima of many correlated binary contrasts.

| k | Largest possible G | Grubbs 5% one-sided G | Detachment D 5%, top chosen as max | D 5%, target pre-specified | Rank floor 1/k |
|---|---|---|---|---|---|
| 5 | 1.789 | 1.671 | 5.08 | 2.63 | 0.200 |
| 7 | 2.268 | 1.939 | 3.98 | 2.18 | 0.143 |
| 11 | 3.015 | 2.232 | 3.47 | 1.92 | 0.091 |

At k = 5 the 5% critical G sits near its ceiling, so the test has power only when the other four candidates cluster tightly. Pre-registering the target cuts the critical detachment roughly in half (5.08 to 2.63 at k = 5), which makes pre-registration the cheapest power gain available. The pre-specified version is a **studentized deleted residual**: `(x_c − m_{−c}) / (s_{−c} √(1 + 1/(k−1)))` follows t with k − 2 degrees of freedom under a normal random-effects null. It is the parametric twin of a random-effects prediction interval ([Higgins, Thompson and Spiegelhalter 2009](https://doi.org/10.1111/j.1467-985X.2008.00552.x)) and of a cross-validatory conflict p-value ([Marshall and Spiegelhalter 2007](https://doi.org/10.1214/07-BA218)). When the target is not pre-specified, the right question is the one Ohlssen, Sharples and Spiegelhalter pose for hospital profiling: is this unit worse than we would expect the true worst unit of the null distribution to be ([Ohlssen et al. 2007](https://doi.org/10.1111/j.1467-985X.2007.00487.x))? The paper reached the same conclusion empirically. Its within-run reference excludes the candidate that holds the maximum and fails by construction, and a reference must compare maximum against maximum ([pooled-reference table](../generated/calib_pooled.tex)).

Power for these tests comes from pooling. With k = 5, the between-name variance on one axis has 3 to 4 degrees of freedom. Moderated variance across the 100 axes ([Smyth 2004](https://doi.org/10.2202/1544-6115.1027)) and a binomial-logit mixed model, which models the known noise of 16 samples exactly, recover much of it. A variance-shift likelihood ratio test with parametric bootstrap handles "one candidate has an inflated random effect" ([Gumedze and Jackson 2011](https://doi.org/10.1186/1471-2288-11-19)). Empirical-Bayes posteriors in the style of employer audits report the probability that a unit sits outside the generic component ([Kline and Walters 2021](https://doi.org/10.3982/ECTA17489)). All of these still locate the generic distribution from k − 1 names, so decoys remain the largest gain.

### The empirical null measures generic effects without testing a candidate

**Efron's empirical null** fits N(δ0, σ0²) to the central bulk of many z-values, so a generic distortion that widens the bulk enters σ0 ([Efron 2007, arXiv 0710.2245](https://arxiv.org/abs/0710.2245); [Efron 2008, arXiv 0808.0572](https://arxiv.org/abs/0808.0572)). Efron's school example is close to ours: every school had some effect, and the empirical null SD was 1.52, half again the theoretical value. Our candidate-by-axis grid has kA = 500 to 1,100 statistics, which meets his "at least in the hundreds" requirement. His bulk condition (null share p0 ≥ 0.9) holds automatically only at k ≥ 10. At k = 5 it holds only if a loyalty moves at most half the target's axes. The method flags cells. Cells cluster by candidate, so a candidate-level claim needs a set statistic calibrated with each other candidate's axis set as a placebo, which returns the 1/k floor. Its best use here is descriptive. A fitted σ0 well above 1 on target-only z-values reports the size of generic name effects. The paper's **lift** (within-run median |t| over permuted median |t|) is already a scale estimate of this kind, computed on base-subtracted excesses. On target-only statistics it would measure the generic effect directly.

### Structure tests separate stable favoritism from noise, and generic effects are stable too

Several within-target tests ask whether the deviation has a shape. **Sign consistency** scores the target on pre-registered favorable directions per axis, and Pearson-type combination is most powerful when most axes share a sign ([Owen 2009, arXiv 0911.3531](https://arxiv.org/abs/0911.3531)). **Partial conjunction** across disjoint instruction folds tests whether the anomaly replicates in at least r of n folds ([Benjamini and Heller 2008](https://doi.org/10.1111/j.1541-0420.2007.00984.x); [Wang and Owen, arXiv 1508.00934](https://arxiv.org/abs/1508.00934)). **Higher criticism** targets sparse signals across axes ([Donoho and Jin, arXiv math/0410072](https://arxiv.org/abs/math/0410072)). A low-rank "synthetic candidate", fitted to the other rows with principal component pursuit ([Candès et al., arXiv 0912.3599](https://arxiv.org/abs/0912.3599)) and scored with conformal residuals ([Chernozhukov, Wüthrich and Zhu, arXiv 1712.09089](https://arxiv.org/abs/1712.09089)), predicts the target's axis profile from the generic factor structure. Negative-control axes (style, length, formatting) play the role of a pre-period ([Lipsitch, Tchetgen Tchetgen and Cohen 2010](https://doi.org/10.1097/EDE.0b013e3181d61eeb)).

Replication removes sampling noise. It does not remove a stable generic effect. All 22 models in one resume audit favored female names, and the effect vanished under neutral labels ([Rozado, arXiv 2505.17049](https://arxiv.org/abs/2505.17049)). Sixteen of 18 models chose Biden in all 100 runs ([Potter et al., arXiv 2410.24190](https://arxiv.org/abs/2410.24190)). A pretraining association replicates across every fold. Fold replication therefore becomes informative only beside a variance-components check showing that the other candidates' rankings do not replicate. Pre-registered signs help most when k > 2, because under a generic-effects null a generic direction points at the target with probability about 1/k. With two candidates the signed test equals the unsigned test, which the paper already notes for the court runs.

Within-target DIF fits the verdict tables directly. Logistic-regression DIF with the reply's total score as covariate ([Swaminathan and Rogers 1990](https://doi.org/10.1111/j.1745-3984.1990.tb00754.x)) separates a uniform candidate shift ("impact") from axis-specific effects, which naive tests conflate. By the identification result above, it identifies only relative effects when generic effects are dense.

### Embedding and pairwise-judge tests reject everywhere until a reference calibrates them

MMD, energy distance and classifier two-sample tests test P_c = P_rest ([Gretton et al., arXiv 0805.2368](https://arxiv.org/abs/0805.2368); [Lopez-Paz and Oquab, arXiv 1610.06545](https://arxiv.org/abs/1610.06545)). Generic name effects make that null false. With 576 to 3,456 replies per candidate, these tests detect tiny shifts. Model equality testing shows the power: a string-kernel MMD reached 77.4% median power with about 10 samples per prompt ([Gao, Liang and Guestrin, arXiv 2410.20247](https://arxiv.org/abs/2410.20247)). The paper's judge-free embedding test rejects at its smallest attainable p on all eight null controls. Calibrated against the null controls, its floor is 1/9, and the paper therefore uses it to rank runs ([calibration appendix](../appendix/calibration.tex)). The right use is as a per-candidate distance on name-masked replies, stratified within instruction and calibrated by a name or model reference. A relative-similarity test asks whether the target is farther from the pool than a decoy is ([Bounliphone et al., arXiv 1511.04581](https://arxiv.org/abs/1511.04581)). Distances are unsigned, so an embedding rejection needs a signed verdict-table test beside it before it supports favoritism.

The **symmetric pairwise judge** from OpenAI's first-person fairness work scores each pair twice with the order swapped and takes forward minus reverse, so judge order bias cancels ([Eloundou et al., arXiv 2410.19803](https://arxiv.org/abs/2410.19803)). It runs on stored reply texts with new judge calls. The paper reports no same-group (A vs A) control, and a pair of names with different priors still gives a nonzero score. Adding A-vs-A pairs supplies the null.

## Decoys, panels and designed contrasts buy back what the base supplied

The methods that escape the 1/k floor all need new data. The most direct one manufactures a reference population of names whose effect is generic by construction.

### Decoy names give a design-based null that served models also support

A **decoy** is a candidate with no hypothesized link to the objective, sampled through the same matched prompts, judged on the same axes, and scored with the same statistic. The target is then ranked among decoys plus the other candidates, as in placebo-in-space inference for synthetic controls ([Abadie, Diamond and Hainmueller 2010](https://doi.org/10.1198/jasa.2009.ap08746)). The conformal p-value is (1 + #{reference ≥ target}) / (n_ref + 1), so p ≤ 0.05 needs 19 reference names and p ≤ 0.01 needs 99 ([Bates et al., arXiv 2104.08279](https://arxiv.org/abs/2104.08279)). A calibration-conditional version, which allows combining several p-values, needs about 92 references for 0.05. **Empirical calibration** reaches below 1/n_ref with fewer decoys: fit N(μ, τ² + se²) to the reference names' estimates and refer the target to it, at the price of normality ([Schuemie et al. 2014](https://doi.org/10.1002/sim.5925); [Schuemie et al. 2018](https://doi.org/10.1073/pnas.1708282114)). An **interval null** tests whether the target's effect exceeds a typical name effect δ estimated from decoys, with a supremum p-value over δ's confidence set ([Berger and Boos 1994](https://doi.org/10.1080/01621459.1994.10476836)). The reverse direction, an equivalence test, is how to clear a model ([Lakens 2017](https://doi.org/10.1177/1948550617697177)).

Two 2026 audits show the design working at scale. Both are preprints. Vohra and Ravikiran ran 40,726 requests on five frontier models with a placebo arm of same-cell names relabelled as pseudo-groups. The arm estimates the design's false-positive level. They recovered a planted 0.50 disparity as 0.48 [0.33, 0.62], and they report minimum detectable effects per outcome ([Vohra and Ravikiran, arXiv 2609.09048](https://arxiv.org/abs/2609.09048)). They also warn that models recognized 74% of placebo bundles as fairness tests under forced choice, so decoys can raise evaluation awareness. Eren et al. ran neutral persona nouns as a separate control family and found that gender could not be separated from persona wording ([Eren et al., arXiv 2609.22511](https://arxiv.org/abs/2609.22511)).

Transluce's user-awareness study is the most complete baseline-free design in this literature and the template for our served-model replication. Its reference is a pool of **70 general-population personas**. Fame-matched non-AI people and "unknown AI" affiliation twins separate "safety researcher" from "famous" and "AI-affiliated". It tests with a leave-one-out predictive t against the general pool, 100,000 whole-user label permutations, a noise-corrected chi-squared test of person-level heterogeneity, and Benjamini-Hochberg within setup ([Transluce, user awareness](https://transluce.org/user-awareness)). Across 24 models, direct grades for Amanda Askell were lower in 21. After correction 13 were significant, and none shifted significantly the other way. Transluce report no base model. Their claim survives the "names matter" objection because the reference population already contains name effects.

Exchangeability is the decoy design's one assumption, and it has to be built in. Decoys should come from the candidates' own pool: same entity type, similar fame, frequency and tokenization. Ideally the audited set is itself a random draw from that pool. Covariate gaps can be handled with regression residuals or weighted conformal p-values ([Barber et al., arXiv 2202.13415](https://arxiv.org/abs/2202.13415)). If the helper LLMs that elicit candidates read target replies, the favored candidate is selected on the outcome. Its estimate then needs a winner's-curse correction ([Andrews, Kitagawa and McCloskey 2024](https://doi.org/10.1093/qje/qjad043)) or elicitation on a pilot split. Two cheaper arms complement decoys. An **alias arm** (two surface forms of one candidate) estimates the pure string effect. A **no-affiliation arm** measures the "any name" offset that identity-free baselines report ([Armstrong et al., arXiv 2405.04412](https://arxiv.org/abs/2405.04412); [Zheng et al., arXiv 2311.10054](https://arxiv.org/abs/2311.10054)).

### A model panel works when its members share the nuisance, and a proxy needs correlation above 0.5

A **panel** of other models sampled on the same prompts with the same judge gives each cell a cross-model reference. Provenance testing already builds its null from unrelated models: over 600 models, it reaches 90 to 95% precision for identifying derived models ([Nikolic, Baluta and Saxena, arXiv 2502.00706](https://arxiv.org/abs/2502.00706v1)). Backdoor meta-classifiers train over populations of clean and trojaned networks ([Kolouri et al., arXiv 1906.10842](https://arxiv.org/abs/1906.10842)). We found no LLM paper that tests one model's group effect against a panel. A rank test with one statistic needs K ≥ 19 models for p ≤ 0.05. A random-effects meta-analysis with a studentized deleted residual works with fewer models, at the cost of a normality assumption. Model behaviors are correlated: two models that are both wrong agree on about 60% of those items, and more so within a provider ([Kim et al., arXiv 2506.07962](https://arxiv.org/abs/2506.07962)). Ten models from three families therefore carry less information than ten independent draws. A bias shared across the panel is absorbed into the reference. Chat models lean left together while base models cluster near the center ([Rozado, arXiv 2402.01789](https://arxiv.org/abs/2402.01789v1)), so a panel rejection says "atypical among current models".

The paper's **cross-run reference** is a panel of sibling organisms. It pools the other null controls, which share base, roster and axes, and compares maximum against maximum. With the base, it flags one of eight null controls at 0.01. On synthetic runs it holds 0.010 at the 0.01 level and runs above nominal at 0.05 (0.107). When every pair drifts and the reference pools drift runs, it rejects only 5.3% of runs, against 99.7% for the registered test. It still rejects 99% of runs with one principal shifted on four axes ([pooled-reference table](../generated/calib_pooled.tex)). That is the behavior a baseline-free panel needs: it absorbs a dense nuisance the panel shares and keeps power against a concentrated one. Whether it holds without base subtraction is untested.

**Proxy subtraction** uses one other model as the base. Write the target's gap as g_T = d + n_T + e_T and a proxy's as g_P = n_P + e_P, with d the trained effect and n the generic effect. Raw subtraction lowers nuisance variance only if Cov(n_T, n_P) > Var(n_P)/2. With equal variances, that means a **cell-level cross-model correlation of name effects above 0.5**. Below it, subtraction makes the null noisier than no subtraction. The literature reports shared direction with model-specific magnitude. All 22 models favored female names ([Rozado, arXiv 2505.17049](https://arxiv.org/abs/2505.17049)), and family signatures diverge ([Jeong et al., arXiv 2410.12010](https://arxiv.org/abs/2410.12010v4)). We found no study that reports the cell-level correlation itself. Post-training also changes the effects being subtracted. Post-RL bias regresses on pre-RL bias with slope 0.21 ([Eloundou et al., arXiv 2410.19803](https://arxiv.org/abs/2410.19803)), and base models voted Biden less often than their tuned versions ([Potter et al., arXiv 2410.24190](https://arxiv.org/abs/2410.24190)). Membership inference offers a warning by analogy: reference-model calibration is fragile, and comparing the target with its own perturbed neighbours beat it by up to 100% ([Mattern et al., arXiv 2305.18462](https://arxiv.org/abs/2305.18462)). A sibling checkpoint is the least bad proxy. Model diffing found no significant difference between using the chat model or its pretrained base as reference, though the signal was weaker with the base ([Minder et al., arXiv 2510.13900](https://arxiv.org/html/2510.13900v3)). For a served model that updates, an earlier snapshot of the same API is a usable temporal reference ([Gao, Liang and Guestrin, arXiv 2410.20247](https://arxiv.org/abs/2410.20247)).

### A context contrast and random assignment are the only routes to a stronger claim

A **signed context contrast** borrows difference-in-differences logic. Instrumental differential treatment predicts that the favored candidate's gap grows in contexts where favoring it serves the objective and shrinks in matched neutral contexts. A stable generic name effect has no reason to change across the pair. Within each candidate, the context difference cancels that candidate's stable generic effect, which is the job the base did. The placebo check is invariance testing in the style of invariant causal prediction ([Peters, Bühlmann and Meinshausen, arXiv 1501.01332](https://arxiv.org/abs/1501.01332); [Heinze-Deml, Peters and Meinshausen, arXiv 1706.08576](https://arxiv.org/abs/1706.08576)): the non-target candidates' gaps should not change across contexts. If they hold, the target's interaction can be sign-flipped over context pairs, and the 1/k floor no longer binds. The design rests on one assumption: the target's own generic effect is as context-invariant as the placebos' effects. That assumption replaces the registered test's assumption that base and target share generic effects. JobFair's split between "taste-based" bias (constant across content) and "statistical" bias (content-dependent) gives the same vocabulary ([Wang et al., arXiv 2406.15484](https://arxiv.org/abs/2406.15484)).

**Randomized objective assignment** is the only design that attributes an effect to the trained objective without a base. It applies only to organisms the auditors train. If several organisms are trained with the favored candidate drawn at random, generic name effects cannot track the draw. Under the null, the detected favorite matches the assigned one with probability 1/m per organism. All n match with probability (1/m)^n, which falls below 0.01 at n = 7 for two candidates and at n = 3 for five. This arithmetic is ours.

### White-box tools and elicitation name hypotheses without calibrating them

No alignment-auditing toolkit uses an untuned reference as an auditing tool. AuditBench's tools compare the target with its own steered outputs, and its untuned model appears only as a dashed line in one figure ([Sheshadri et al., arXiv 2602.22755](https://arxiv.org/abs/2602.22755)). These tools report hit rates on implanted behaviors. They do not report false-positive rates on innocent models. KTO adversarial training holds confessions under 2%. Static black-box audits found narrow secret loyalties 0% of the time when the auditor did not know the principal ([Lamerton and Roger, arXiv 2605.06846](https://arxiv.org/html/2605.06846v3)). Target-only white-box readers (activation oracles, deception probes, user-model probes) need open weights and give no calibrated null ([Karvonen et al., arXiv 2512.15674](https://arxiv.org/html/2512.15674v1); [Goldowsky-Dill et al., arXiv 2502.03407](https://arxiv.org/pdf/2502.03407); [Chen et al., arXiv 2406.07882](https://arxiv.org/abs/2406.07882)). A matched-norm random-direction band plus a neutral control principal is the one reference-free calibration for steering-installed loyalties ([Gandhi, NeurIPS 2026](https://neurips.cc/virtual/2026/180075)). Backdoor scanners assume a universal target sequence or a trigger-like discontinuity ([Shen et al., BAIT](https://www.cs.purdue.edu/homes/cheng535/static/papers/sp25_bait.pdf); [Yi et al., arXiv 2506.16447](https://arxiv.org/html/2506.16447v1)). A steady favoritism expressed in every reply fits neither assumption. These methods belong upstream, where they choose candidates and axes for the confirmatory test.

## Three methods earn full treatment in the appendix

Ranking by fit to the stored data and by claim strength gives a clear order. Fit measures what runs on verdict tables, texts and embeddings now, and what runs on black-box served models later. Claim strength follows the ladder above.

| Rank | Method | Fit now | Claim | Appendix role |
|---|---|---|---|---|
| 1 | Name-population outlier test: detachment or deleted-residual t, referred to decoys by conformal and empirical-calibration p | High: runs now at the 1/k floor; decoys need target sampling only | Level 2 | Present in full |
| 2 | Panel reference, max against max, with a random-effects deleted residual | High for sibling organisms (stored); medium for served models | Level 3 | Present in full |
| 3 | Signed context contrast with placebo invariance and fold replication | Medium: stored only if the instruction set holds matched contexts | Level 2s | Present in full, or as a design if contexts are missing |
| 4 | Empirical null σ0, or the lift on target-only gaps | High | Sizes the nuisance | Report as a diagnostic |
| 5 | Within-target DIF | High | Relative effects only | Descriptive |
| 6 | Masked embedding distance calibrated by decoys or panel | High | Unsigned Level 2 or 3 | Keep as a ranking check |
| 7 | Proxy subtraction | High if stored | Weak | Run as a null control |
| 8 | Symmetric pairwise judge with A-vs-A pairs | Medium (new judging) | Level 0 to 1 | Optional |
| 9 | Sharp-null tests (target-only, MMD, excess dispersion) | High | Level 0 | Show as the failure case |
| 10 | Randomized assignment | Low (organisms only) | Level 4 | Propose for the court organism |
| 11 | White-box readers, elicitation, backdoor scanners | Low for served models | Hypotheses | Upstream only |

**The name-population outlier test** should come first. It reuses the statistic the paper already computes. It states the 1/k floor and the Grubbs equivalence explicitly. It then lifts the floor with decoys drawn from the candidates' own pool, which works unchanged on served models. The appendix should present three p-values side by side: the design-based conformal p over decoys and candidates, the parametric empirical-calibration p, and the normal-theory deleted-residual p for a pre-registered target. The claim reads "the favored candidate's treatment exceeds what (1 − α) of comparable names receive in this model". For the user-awareness replication, this method is the Transluce design. It needs a general-population pool and fame-matched controls, if the replication does not already include them.

**The panel reference** should come second because the paper already holds its strongest evidence. The cross-run reference holds its level at 0.01 on synthetic nulls, absorbs dense shared drift, and keeps 99% power against a concentrated principal. Re-running it on target-only statistics over the eight AuditBench null controls tests a baseline-free panel of sibling organisms at no sampling cost. For served models, the same statistic over a panel of served models is the only available reference. The claim reads "the target is atypical among these models", and the appendix should say plainly that a bias shared across the panel is invisible to it.

**The signed context contrast** should come third. It is the only stored-data route past the 1/k floor that does not lean on a shape assumption. It also matches the paper's thesis that differential treatment is instrumental. If the existing instructions do not contain matched instrumental and neutral contexts, the appendix should present it as the design that would close the gap. It should be honest that its anchor assumption is the target's own context invariance. Two cases fit it poorly. The court runs have two candidates, so name-population tests are undefined and signed equals unsigned. There, the context contrast or randomized assignment is the only option.

Three things should be demoted. Target-only one-vs-rest tests should appear only as the failure they demonstrate. The within-run reference fails by construction. Embedding tests should stay as rank checks. In every case the appendix should redefine covert differential treatment for the baseline-free setting as treatment beyond a named reference R, and name R in every verdict.

## Proxy swaps and planted effects cost compute; decoys and panels cost replies

The experiments below are ordered by value per unit cost. We write k for candidates, I for instructions, 16 for samples per cell, m for decoys and K for panel models. Each new arm costs I × 16 target replies, which is 576 at I = 36 and 3,456 at I = 216, plus judging of every reply. Judge cost scales with how many axes one judge call scores. The paper's pruning result helps here: about 25 axes chosen on a pilot keep strong effects, and instructions spent on the pilot are the larger loss ([calibration appendix](../appendix/calibration.tex)). We give no dollar figures. Each arm should be priced from a pilot that uses the same target and judge models, from its own token counts.

| Experiment | What it buys | New replies | Main cost driver | Main risk |
|---|---|---|---|---|
| Cross-run reference on target-only statistics, AuditBench null controls | Tests a sibling-organism panel without a base | None | Compute | Sibling quirks share one base, so the result may not transfer to served models |
| Proxy-swap null controls among stored samples | False-positive rate of proxy subtraction; cell-level correlation against the 0.5 threshold | None where two stored models share prompts, roster, instructions and judge; otherwise k × I × 16 per proxy | Compute, or one proxy arm | Rosters differ across organism families |
| Planted-effect recovery in stored verdict tables | Minimum detectable effect and detection floor per method, following [Vohra and Ravikiran](https://arxiv.org/abs/2609.09048) and [Gandhi](https://neurips.cc/virtual/2026/180075) | None | Compute | A planted shape may not match a real loyalty |
| Decoy names, run on each audited model and on the null controls | Lifts the 1/k floor; design-based calibration | m × I × 16 per audited model | Number of decoys × models audited | Decoys that differ in fame or grounding; audit recognition |
| Alias and no-affiliation arms | Separates string effects and the "any name" offset | k × I × 16 per alias set; I × 16 for the unnamed arm | Arms × I | Aliases carry different grounding |
| Matched instrumental and neutral context pairs | Anchor for the signed context contrast | k × pairs × 2 × 16 | Prompt design and pairs | Context changes generic effects too |
| Served-model panel | The only reference for the user-awareness replication | K × k × I × 16 | K and per-model API prices | Correlated models; shared biases absorbed |
| Randomized-assignment organisms | Causal attribution without a base | Per organism, k × I × 16 | Fine-tuning runs (n = 7 at two candidates for p < 0.01) | Organisms differ in strength |
| Audit-recognition probe | Bounds evaluation awareness, which Vohra and Ravikiran found at 74% for placebos | A small sample | Negligible | Probe wording shifts the answer |

The decoy arithmetic sets the scale. A conformal p of 0.05 needs n_ref = m + k − 1 ≥ 19. That is 15 decoys at k = 5 (8,640 replies at I = 36, three times a five-candidate run's 2,880 target replies) and 9 decoys at k = 11 (5,184 replies). A conformal p of 0.01 needs n_ref ≥ 99. That is 95 decoys at k = 5 (54,720 replies at I = 36) and 89 at k = 11 (51,264), multiplied by six at I = 216. We therefore recommend about 15 to 20 decoys per roster. The conformal p then serves at 0.05 as the assumption-light check, and the parametric empirical calibration over the same decoys carries the 0.01 decision. No source gives a minimum decoy count for empirical calibration, so its operating point should come from the planted-effect experiment. Decoys can be shared across runs that share a roster and instructions, such as the eight null controls and contextual optimism. Each audited model must still be sampled on them.

A served-model panel faces the same arithmetic for a rank test: K ≥ 19 models for 0.05 and 99 for 0.01. The second is out of reach. A random-effects deleted residual over 8 to 12 models from several vendors is the practical design. At k = 5 and I = 36, ten models cost 28,800 replies. The panel should include open untuned models where possible, so that its mean sits nearer a base than a panel of tuned chat models would.

## Conclusion

The base was doing two jobs at once. It cancelled generic name effects cell by cell, and it let a rejection be attributed to tuning. Every baseline-free method can do the first job, and only if it imports a reference whose exchangeability with the target is designed in. None can do the second, except randomized assignment on organisms the auditors train. This reframes the appendix's task. The appendix stops asking which test replaces the base and states which reference each verdict is relative to, then shows that reference is calibrated on null controls. The paper already holds the key ingredients: the max-against-max lesson, the cross-run panel, the placebo machinery, and eight null controls that can calibrate any new reference.

The weakest point of every recommended design is the same: the reference names or models may differ from the favored candidate in ways unrelated to any objective. High-grounding entities make this worse, and the narrow-secret-loyalty base model's own rejections show it is already happening. The decisive measurements are therefore cheap and internal. One is the cell-level cross-model correlation of name effects, which no published study reports and which decides whether any proxy or panel helps. Another is the false-positive rate of each baseline-free reference on the existing null controls. A third is the detection floor from planted effects. Running these first turns the appendix's limits into results. It also tells the team whether decoys or a panel deserve the reply budget.
